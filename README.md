# 136スタジオ予約サイト

会員登録・ログイン・空き枠確認・予約保存・マイページをVercel FunctionsとNeon Postgresで提供します。予約の前後15分を含む重複をデータベースで防ぎます。

## 構成

- 公開画面：`public/`、API：`api/`、共通処理：`lib/`。
- Vercel：Node.js 24.x、Output Directory `public`。
- 必須環境変数：`DATABASE_URL` と32文字以上のランダムな `AUTH_SECRET`。秘密値をソースに保存しないでください。
- `schema.sql` は新規データベース向けの参照定義です。既存DBは列・型・制約を確認し、既存データを保持してください。
- ローカル検証：`npm test`。

## 利用ルール

利用枠は9:00〜10:00、11:00〜12:00、13:00〜14:00、15:00〜16:00、17:00〜18:00、19:00〜20:00、21:00〜22:00の7枠です。通常は入退室に前後15分を含み、入退室枠の間に30分空きます。最終枠のみ入退室20:45〜22:00で、後15分はありません。1枠1,200円。複数枠は一括トランザクションで枠ごとの予約を登録し、空き時間を予約に含めません。

予約がDBに保存された後に、部屋別のPayPay QRと案内を表示します。支払い案内を閉じても決済確認済みにはならず、運営者による確認が必要です。

約款、ロゴ、部屋別PayPay QR、提供された2部屋の写真を使用しています。検証結果は `VALIDATION.md` を参照してください。

## ログインの暗証番号

新規登録では半角数字4桁の暗証番号を設定します。先頭の0も保持し、ソルト付きハッシュで保存します。既存のパスワードでもログインでき、マイページで現在のパスワードを確認したうえで数字4桁へ変更できます。メールアドレスごとに15分間の失敗回数を数え、5回の失敗後は15分間のウィンドウが終了するまで試行を制限します。

## 予約管理とキャンセル

会員はマイページで、自分の予約を準備開始前にキャンセルできます。履歴はcancelledとして保持し、空き枠に反映します。返金は自動処理しません。

管理者入口は `/admin.html`。`ADMIN_USER_ID` と `ADMIN_EMAIL` の両方が、認証済みの登録会員に一致する場合だけ管理できます。メールアドレスだけで管理者にしません。一般会員の新規登録から管理者権限を設定できません。管理者は月間時間表で申込者名・電話・メールを確認し、会員を選んで複数枠をまとめて予約、キャンセルできます。複数日の登録は一括トランザクションで、1枠でも競合すると全件ロールバックします。

ログインセッションは利用中のサイトのホスト名に限定します。検証環境や別のURLのセッションを使い回せません。この更新前のセッションは、再ログインが必要です。

管理者の利用開始：指定した実会員を登録後、本番の管理者ID・メール設定を更新し、再デプロイして反映します。管理者入口から登録済みの暗証番号でログインしてください。

予約受付期限：日本時間の今日から利用者は1カ月先、管理者は3カ月先まで（期限日を含む）。対応する日がない月は月末まで。過去の月の管理・キャンセルは引き続き可能です。

追加管理者：ADMIN_ACCOUNTSに登録済み会員のIDとメールの組をJSON配列で設定します。既存のADMIN_USER_ID・ADMIN_EMAILの管理者も維持します。IDとメールの両方が一致した会員だけ管理できます。
