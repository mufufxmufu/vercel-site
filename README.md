# 136スタジオ予約サイト

会員登録・ログイン・空き枠確認・予約保存・マイページをVercel FunctionsとNeon Postgresで提供します。予約の前後15分を含む重複をデータベースで防ぎます。

## 構成

- 公開画面：`public/`、API：`api/`、共通処理：`lib/`。
- Vercel：Node.js 24.x、Output Directory `public`。
- 必須環境変数：`DATABASE_URL` と32文字以上のランダムな `AUTH_SECRET`。秘密値をソースに保存しないでください。
- `schema.sql` は新規データベース向けの参照定義です。既存DBは列・型・制約を確認し、既存データを保持してください。
- ローカル検証：`npm test`。

## 利用ルール

営業時間9:00〜21:30内に前後15分を収めるため、予約時間は9:15〜10:15から20:15〜21:15までの60分枠です。前後15分を含む90分を確保するため、隣接する60分枠は同じ部屋で選べません。1枠1,200円です。

予約がDBに保存された後に、部屋別のPayPay QRと案内を表示します。支払い案内を閉じても決済確認済みにはならず、運営者による確認が必要です。

約款、ロゴ、部屋別PayPay QR、提供された2部屋の写真を使用しています。検証結果は `VALIDATION.md` を参照してください。
